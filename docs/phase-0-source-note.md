# Phase 0 source note

The governing implementation baseline is **Canonical Blueprint & Master Build Prompt v1.1**. The source document defines the platform as an independent multi-tenant-ready CPD SaaS, separates internal committee approval from external SCFHS accreditation, requires RLS, append-only audit, role-context separation, versioned templates/methodologies/policies, interim-vs-final impact reporting, and phase-gated delivery.

The implementation repository stores normalized Markdown execution documents rather than real institutional data or branding.
